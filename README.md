## 👨‍💻 Sobre mim

Atualmente, atuo como **Analista de QA**, com foco em garantir a qualidade e a confiabilidade de aplicações web e mobile por meio de testes manuais, testes de API e análise de funcionalidades.

Também possuo conhecimentos em **desenvolvimento Full Stack**, com experiência em tecnologias de front-end e back-end, bancos de dados e construção de aplicações web modernas. Tenho familiaridade com JavaScript, TypeScript, Vue.js, Angular, Node.js e MySQL, além de explorar novas tecnologias para ampliar minhas habilidades.

Busco unir minha experiência em qualidade de software com meus conhecimentos em desenvolvimento para contribuir com a criação de soluções eficientes, funcionais e com uma boa experiência para o usuário.

---

## 🎯 Objetivos

- **QA:** garantir a qualidade de produtos digitais por meio de testes funcionais, exploratórios, regressivos e de API.
- **Desenvolvimento Full Stack:** desenvolver aplicações modernas, responsivas e escaláveis, utilizando tecnologias de front-end e back-end.
- **Aprendizado contínuo:** aprimorar minhas habilidades técnicas e explorar novas ferramentas e tecnologias.
